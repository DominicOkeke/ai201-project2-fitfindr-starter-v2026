### 1. `search_listings`
- **Description:** Searches the inventory listings file for items matching a text query, size, and maximum price.
- **Inputs:**
  - `description` (str): Search keywords or item description (e.g., "vintage graphic tee").
  - `size` (str): Clothing size filter (e.g., "M", "L", "XL").
  - `max_price` (float): Upper price ceiling filter.
- **Returns:** A list of listing dicts, where each dict contains `title` (str), `price` (float), `size` (str), `platform` (str), and `description` (str).
- **Empty Case:** Returns an empty list (`[]`) when no listings match the criteria.

### 2. `suggest_outfit`
- **Description:** Takes a selected clothing item and the user's wardrobe to generate outfit combination ideas.
- **Inputs:**
  - `new_item` (dict): The target item dict containing `title`, `price`, `size`, `platform`, and `description`.
  - `wardrobe` (dict): The user's wardrobe dictionary containing a list of owned clothing items under `items`.
- **Returns:** A string containing markdown-formatted outfit recommendations and styling tips.
- **Empty Case:** Returns a string with general styling advice for the item when the wardrobe is empty.

### 3. `create_fit_card`
- **Description:** Generates a short, engaging social media caption highlighting the selected item and suggested outfit.
- **Inputs:**
  - `outfit` (str): The outfit advice generated by `suggest_outfit`.
  - `new_item` (dict): The selected item dict containing item details.
- **Returns:** A concise string caption formatted for posting.
- **Empty Case:** Returns an error message string if required inputs are missing or invalid.
